## 🎯 Sobre este repositorio

Este repositorio contiene todos los proyectos y ejercicios realizados durante las clases de desarrollo con Laravel. Aquí encontrarás desde ejercicios básicos hasta proyectos más complejos que abarcan diferentes aspectos del framework.

## 🚀 Tecnologías utilizadas

- **Laravel** - Framework PHP para desarrollo web
- **PHP** - Lenguaje de programación backend
- **MySQL** - Sistema de gestión de bases de datos
- **Composer** - Gestor de dependencias PHP
- **Blade** - Motor de plantillas de Laravel
- **Eloquent ORM** - Object-Relational Mapping

## 💡 Conceptos aprendidos

- ✅ Rutas y controladores
- ✅ Migraciones y seeders
- ✅ Modelos y relaciones (Eloquent)
- ✅ Vistas con Blade
- ✅ Autenticación y autorización
- ✅ Validación de formularios
- ✅ Middleware
- ✅ Relaciones entre tablas (One to One, One to Many, Many to Many)

## 🛠️ Instalación y configuración

Para ejecutar cualquier proyecto de este repositorio:

```bash
# Clonar el repositorio
git clone https://github.com/LuciaRuiz0810/laravel.git

# Navegar al proyecto deseado
cd laravel/nombre-del-proyecto

# Instalar dependencias
composer install

# Copiar archivo de configuración
cp .env.example .env

# Generar key de aplicación
php artisan key:generate

# Ejecutar migraciones
php artisan migrate

# Ejecutar seeders
php artisan db:seed

# Iniciar servidor de desarrollo
php artisan serve
```
